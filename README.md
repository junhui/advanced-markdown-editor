# Advanced Markdown Editor

A high-performance, feature-rich markdown editor built with Next.js and React.

## Features

- Real-time markdown preview
- Performance-optimized rendering
- Toolbar with common formatting actions
- Table support
- Tooltip UI components
- Responsive layout

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
npm start
```

## Project Structure

```
src/

├── pages/
```
